Al Batool Hall (صالة البتول) 📚📱

An intelligent educational tracking system designed to monitor student progress, academic performance, and daily attendance through unique QR codes and secure access codes.

🌟 Overview

Al Batool Hall is a student management web application built to eliminate the hassle of traditional paper-based attendance and performance tracking. The platform ensures seamless tracking by assigning every student a unique QR code for instant attendance check-ins, alongside custom access codes for managing records, grades, and absence logs efficiently.

🎯 Why It Matters & Key Benefits

Automated Attendance: Replaces manual roll calls with fast, contactless QR code scanning to save instructional time.

Student Performance Monitoring: Tracks individual academic progress and grades over time to help educators identify who needs extra support.

Dual-Method Verification: Supports both QR code scanning and direct code entry for flexible attendance and absence logging.

Centralized Data Storage: Keeps all student logs, attendance histories, and grade reports neatly organized in one accessible location.

✨ Key Features

QR Code Attendance System: Instant check-in system where each student can scan their personal QR code.

Code-Based Absence Logging: Secure identification codes to track attendance statuses and absences accurately.

Progress Tracking Dashboard: Real-time views for reviewing student performance metrics and academic milestones.

Firebase Backend: Reliable cloud integration for real-time syncing of attendance data and student profiles.

🛠️ Tech Stack

Frontend: HTML5, CSS3, JavaScript (Clean, responsive layout for web browsers and mobile scanners)

Backend & Database: Firebase (Real-time database and secure data management)

Utilities: QR code generation and scanning libraries

🚀 Getting Started

Clone or download the project repository.

Open the project folder in your preferred code editor (like VS Code).

Connect your Firebase credentials in the configuration files.

Run the application using a local web server to test the QR check-in workflow.

💡 Vision

Al Batool Hall aims to modernize classroom management in educational centers, bringing digital efficiency, precise attendance tracking, and transparent progress reports to both students and educators.
